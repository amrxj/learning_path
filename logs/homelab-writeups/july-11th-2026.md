## Bonus Notes
- Inheritance: basically OUs inherit policies from their parents unless it's blocked.
- Enforced: like it says, it's applied to everyone regardless if blocked or not. 
- Security Filtering: allows GPO applied only to specific users or groups instead of everyone in a container. 
- LSDOU: basically an order of how windows checks if policy is applied, it goes:
    - Local
    - Site
        - Domain
    - Organizational Unit (OU).
- policies applied closer (i.e. local instead of site) take priority over higher-level ones unless it's enforced.
