## Day 8 - SOC Homelab

### What Happened? 
- Learned about SYSMON (System Monitoring) and how it's used. 
    - provides better detail than generic Event Viewer.
    - helps investigate process execution, network activity, file creation, registry modifications.
    - A process can be traced through parent proceses, cmd line, network connections and file hashes.
    - ex. Event ID 1 (process creation) is a key event/starting point of investigations.
