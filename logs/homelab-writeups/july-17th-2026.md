## Day 9 - SOC Homelab

### What Happened? 
- installed SYSMON
- verified sysmon was active and logging events through event viewer.
- generated an example Sysmon Process Creation event (which goes under Event ID 1) by running basic windows cmds in cmd prompt. 
- investigated the following:
    - running the command ipconfig /all
    - sysmon shows process creation event.
        - tells me what was run (ipconfig.exe)
        - the parent process (cmd.exe)
        - who ran it (in this case, me using the admin account).
        - the command used (ipconfig /all)
